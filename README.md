# Premium Fitness Studio (PFS Gym) - Official Brand Portfolio

A modern, multi-page culinary and athletic portfolio website designed for **Premium Fitness Studio**, located at 129/1 Santoshpur Avenue, Kolkata.

## Live Website & Repository
- **Live Website URL:** https://cloudempiretech.github.io/premium-fitness-studio-kolkata/
- **GitHub Repository:** https://github.com/cloudempireTech/premium-fitness-studio-kolkata

## Architecture & Standards
- Multi-Page Architecture: `index.html`, `offerings.html`, `about.html`, `catering.html`, `gallery.html`, `reviews.html`, `contact.html`
- TheDivine floating frosted pill navbar with single-line one-word tabs
- Hero 16:9 landscape video starting at absolute top (`top: 0`) with +faststart streaming optimization
- Sticky floating tab filter rail with smooth horizontal swipe
- Pure brand portfolio (zero e-commerce, zero prices, zero carts)
- Official WhatsApp contrast standard: White speech bubble + green handset on green buttons
- Full mobile responsiveness with zero horizontal overflow across 360px, 375px, and 390px viewports
- Complete multi-resolution favicon suite
